# PjM6_ProAnalysis
Групповой учебный проект по продуктовому анализу цифрового сервиса «ЛитРес» и разработке предложений по его развитию.

В команде из трёх человек участвовала в исследовании продукта, анализе целевой аудитории, формировании продуктовых гипотез и разработке стратегии развития.

Моя основная зона ответственности этапы подготовки и исследования: сегментация целевой аудитории, выявление потребностей и пользовательских барьеров, определение приоритетных сегментов и формулирование проверяемых гипотез с использованием HADI.

Также участвовала в проработке User Stories, Jobs-to-be-Done, пользовательских персон, анализе результатов CustDev, продуктовых метрик и юнит-экономики.

Результат: подготовили комплексный анализ продукта с предложениями по улучшению пользовательского опыта, повышению конверсии и удержанию аудитории. Проект помог закрепить навыки продуктового анализа, исследования потребностей пользователей и принятия решений на основе данных.
